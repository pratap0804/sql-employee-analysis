# SQL Employee Department Analysis

### Project Overview
This project solves 6 real business questions using SQL concepts.

### Concepts Used
- GROUP BY & HAVING
- Single-Row Subquery (AVG salary)
- Multi-Row Subquery (IN clause)
- INNER JOIN & LEFT JOIN
- Aggregate Functions: MAX, COUNT, AVG

### Queries Solved
1. Max salary per department
2. Departments with >1 employee
3. Employees earning above average salary
4. Employees in Hyderabad location
5. Employee + Department details (JOIN)
6. Department-wise count & average salary
